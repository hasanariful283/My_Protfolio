# Md Ariful Hasan — Personal Portfolio

A responsive, single-page personal portfolio built with HTML, CSS, and vanilla JavaScript. No build tools, backend, database, or package installation are required.

## Run locally
1. Extract the ZIP file.
2. Open the `Md_Ariful_Hasan_Portfolio` folder in Visual Studio Code.
3. Install the **Live Server** extension (optional).
4. Right-click `index.html` and choose **Open with Live Server**.
   - Alternatively, open `index.html` directly in a browser.

## Personalize before publishing
- **Email:** Replace `YOUR_EMAIL@example.com` in `index.html` and `js/main.js` with your actual email address.
- **Travel agency:** Replace `[Travel Agency Name]` and `[Job Title]` and add the employment dates.
- **Teaching:** Replace `[Self-employed / Organization name]` if applicable.
- **CV:** Put your PDF at `assets/cv/Ariful_Hasan_CV.pdf`. The Download CV button points to this path. The placeholder folder does not contain a CV.
- **Profile photo:** The hero currently uses an initials avatar (`AH`). You can replace it with your photo by editing the `.avatar` element in `index.html` and its CSS.
- **Projects:** Edit the project cards in `index.html`; add genuine project screenshots and GitHub repository links when available.

## GitHub upload
1. Create a new GitHub repository, for example `ariful-hasan-portfolio`.
2. Upload the contents of this project folder (including `index.html`, `css`, `js`, and `assets`).
3. Commit and push the files.

## GitHub Pages
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site. Your website URL will appear in the Pages settings.

## Notes
- This is a static site and is compatible with GitHub Pages.
- Google Fonts are loaded online; the website uses fallback fonts if they are unavailable.
- The contact form uses `mailto:` and opens the visitor's email application. It does not send or store messages itself.
- No unverified programming languages, frameworks, publications, or achievements have been added.
